# 📝 Flutter To-Do App

A clean and simple **To-Do application built with Flutter and Dart**.  
This project was created to practice Flutter UI development, state management, user input, dialogs, navigation, and interactive task handling.

## ✨ Features

- ✅ Add new tasks using a dialog
- ☑️ Mark tasks as completed
- 🗑️ Delete tasks with a confirmation dialog
- 📊 Task summary showing Total, Completed, and Pending tasks
- 🧭 Navigation Drawer for app navigation
- ⚙️ Settings screen
- 🏠 Home / Tasks screen
- 🎨 Clean and responsive Flutter UI
- 📱 Tested on an Android device/emulator

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/basic_app.git
```

### 2. Open the project

```bash
cd basic_app
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
